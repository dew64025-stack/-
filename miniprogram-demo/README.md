# 材智通 HTML 原型 → 微信小程序

这是由 `stitch_web_repository_frontend_designer/_1`～`_21` 的静态 HTML 原型转换出的
**可导入微信开发者工具**的原生小程序工程。

## 导入

1. 微信开发者工具 → 导入项目
2. 目录选择：

   ```text
   D:\caizhitong-review\miniprogram-demo
   ```

3. AppID：
   - 有权限时填 `wx019bf0b6d1a50ad3`
   - 没有权限时选择“测试号”
4. 打开 **详情 → 本地设置**，勾选：

   ```text
   ☑ 不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书
   ```

5. 编译后进入首页，会看到 21 个页面入口。

## 页面操作

- 首页列出全部 21 个原型页，点击可进入。
- 每个原型页右下角有一个悬浮的 **“‹ 返回”** 按钮：
  - 从首页进入时返回上一页
  - 直接打开某个页面时返回首页
- 原型页是**静态视觉转换**：页面里的按钮、星级评分、预约弹层、表单提交等没有逐一重写，
  点击不会执行业务动作。这是转换边界，不是页面卡死。

## 后端联调

首页会自动调用：

```text
GET http://127.0.0.1:8080/api/v1/campuses
```

后端当前运行在 `127.0.0.1:8080`，成功后首页显示“后端连接成功：示范大学”。

真机调试时：

1. 把 `utils/request.js` 的 `BASE_URL` 改成电脑 WLAN IPv4，例如：

   ```js
   const BASE_URL = 'http://10.56.139.4:8080/api/v1';
   ```

2. 手机与电脑在同一 Wi-Fi
3. Windows 防火墙放行 TCP 8080
4. 开发者工具保持“不校验合法域名”

正式版必须使用 HTTPS 域名，并在微信公众平台配置 request 合法域名。

## 转换边界

- **首页 / 机会 / 互助已接后端实时数据**：页面顶部有“后端实时数据”面板，调用公开接口；其余原型页仍是静态视觉转换。
- HTML 里的表单提交、星级评分、预约弹层等脚本没有逐一重写。
- Material Symbols 图标用 emoji 代替，避免加载远程图标字体。
- 12 张原型图片已下载到 `assets/images`。
- Tailwind 工具类已编译为 `app.wxss`；新增页面或样式直接写 WXSS。
- 未接入登录态。真实登录需要后端配置 `WECHAT_APP_ID` / `WECHAT_APP_SECRET`，并在页面里接
  `wx.login` → `/auth/wechat/login`。

## 重新生成

修改原型 HTML 后运行：

```powershell
python tools\convert_prototypes.py
python tools\apply_api_panels.py
```

生成脚本在 `D:\caizhitong-review\tools\convert_prototypes.py`。重新生成后，在微信开发者工具里
点一次 **编译**（或 Ctrl+B）即可刷新。
