### 6.3 单位

统一 `rpx`，换算基准 375px 设计稿 = 750rpx，即 **1px = 2rpx**（16px 边距 → 32rpx）。

### 6.4 WXML 标签铁律（最容易踩的坑）

- `<text>` 只支持文字样式，**不支持背景色/圆角/内边距/边框**。
- 带「背景 + 圆角 + 内边距」的元素（徽章 badge、胶囊 chip、圆点 dot、带底代码块）**一律用 `<view>`**。
- `<text>` 内可嵌套 `<text>` 做局部加粗/变色，例如 `<text>版本为 <text class="primary-text mono">v1.2</text>…</text>`。
- 图标 emoji 用 `<text class="ico ...">emoji</text>` 即可。

## 八、待办与注意事项（交接重点）

1. **图片占位**：原型的 Google 外链图片与内联 SVG 已替换为 `ph-image` 占位块（含描述文字）。接下去需要：设计/准备本地图片资源，放到 `assets/` 并改用 `<image src="/assets/...">`。
2. **页面跳转未打通**：详情页之间的 `wx.navigateTo` 目标多为演示占位，需按真实业务流程串联（例如：服务页 → 座位预约 → 选座 → 凭证；互助 → 详情 → 聊天）。
3. **交互是本地演示**：所有状态仅用 `data + setData` 本地模拟，无后端接口。接入真实 API 时，把 `setTimeout` 模拟改为 `wx.request`，并保持错误码/合规文案（如 409、502、422、403 等异常页的契约文案）。
4. **Tab 图标**：当前底部 Tab 为纯文字（`app.json` 未配置 iconPath）。如需图标，准备 PNG 图标（普通 + 选中两态各 5 张），在 `app.json` 的 `tabBar.list` 里补 `iconPath` / `selectedIconPath`。
5. **下拉刷新/分享**：目前未配置，可按需在 `app.json`/各页 `.json` 增加。
6. **回退逻辑**：所有页面 `goBack()` 采用「有上一页则 `navigateBack`，否则 `switchTab` 回首页」的通用实现。

## 九、源文件对照表

`_N/code.html` → 页面（完整映射见「三、当前完成度」表）。转换规则细节见 `CONVERSION_SPEC.md`：

- Google 图片/内联 SVG → `ph-image` 占位；Material Symbols → emoji
