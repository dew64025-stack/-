# 材智通 · 原版内容手机适配

## 微信开发者工具导入

1. 解压整个文件夹。
2. 在微信开发者工具中选择“导入项目”，选择包含 `app.json`、`project.config.json` 的这一层目录，不要只导入 `pages`。
3. 沿用原项目 `project.config.json` 中的 AppID。没有该 AppID 开发权限时，请在开发者工具中选择你有权限的 AppID，不要填写 AppSecret。
4. 编译后选择 320、375、414 等手机宽度检查页面；5 个一级入口仍为首页、机会、服务、互助、我的。

## 本版改了什么

- 保留原有 21 个页面，不改页面文字、图片/占位图、顺序和业务展示。
- 不改 WXML、JS、页面配置、AppID，不混入另一个后端联调版本。
- 只增加手机宽度、按钮换行、小屏座位分列、底部按钮留白和安全区样式。
- 综合服务专区的六个快捷入口固定为三列两行，保留圆形图标、原顺序、文字和点击事件。
- 互助页搜索框与“发互助”按钮固定横排，分类不拆成竖排；教材卡片的循环人数与“收藏 / 联系自提”按钮横排，原文与点击事件不变。
- 小屏 B 区座位由 8 列调整为 4 列展示，座位编号、顺序、状态和数量不变。此为屏幕排版，不代表真实场地平面变更。
- 原目录 `D:\D\pages(1)` 不覆盖、不修改。本文件夹为独立副本。
- 不分发原机的 `project.private.config.json`，避免混入本地模拟器/环境设置；工具会按本机情况重新生成。

## 范围说明

本版只做原版界面适配。原版中已有的演示数据、占位图片、模拟交互均按要求保留，不代表后端或真实微信授权已经联调完成。不要把界面中的演示成功提示当作真实业务记录。

验证结果和截图在同级的“原版手机适配-验证”文件夹（若随包提供）；原有 README 和交接资料保持原样，本说明仅补充这次适配内容。
