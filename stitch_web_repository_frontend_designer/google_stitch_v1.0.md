# 材智通 · Google Stitch 设计提示词集

> 版本：v1.0（2026-10-15）  
> 对应规范：`design/DESIGN.md`、《材智通小程序前端部署文档（修订版）》§4.1与§11、《项目规划书》及《后端接口 v1.1》。  
> 原则：全中文、校园可信风格；所有设计素材严格采用**虚构脱敏数据**，严禁使用真实姓名、手机号、学号、宿舍号、聊天记录及密钥；演示数据全流程持续标识。

---

## 一、使用步骤与工作流

1. 打开 Google Stitch 并登录，新建项目（建议项目名：`caizhitong`）。
2. **设备类型**：统一选择 **Mobile**（移动端竖屏，标准视口宽度 ~390px，微信原生小程序形态）。
3. **设计系统（Design System）**：先导入或建立 `Academic Nexus` 设计系统（主色 `#1B4965` 学院深蓝、功能合规绿 `#2D7A58`、警示橙红 `#C55A38`、冷白底色 `#F8FAFC`）。
4. **生成顺序**：
   * **第 1 批**：五大一级 Tab 页面（首页、机会、服务、互助、我的）；
   * **第 2 批**：核心业务二级详情页（材料清单与预检详情、图书馆时段与选座、工单状态流转与评价、匿名发帖与互动）；
   * **第 3 批**：关键异常态与缺省页（学生认证引导、空列表态、网络异常/版本冲突、文件扫描中/阻断态）。

## 五、合规与验收清单（执行自检）

在每个页面生成完成后，必须逐项核对：
1. **六大来源顶层字段**：在涉及外部数据的卡片上，是否明确标识 `sourceType: "demo"` 或 `sourceName: "校园演示提供器"`？
2. **脱敏严密性**：手机号是否始终脱敏为 `138****0000`？学号是否脱敏？人名是否采用虚拟化占位（如林学长、张师傅）？
3. **零在线支付**：是否杜绝了微信支付、收银台、保证金等金融交易交互？
4. **可解释信用**：是否仅展示守约履约历史事件，完全杜绝了未知的 AI 人格分数？
5. **匿名不可串联**：匿名社区内各帖笔名是否彼此独立且随机？
