# 材智通参赛介绍

以下三段分别不超过 150 字，按中文及标点逐字符统计；不将待配置的 AI 或学校接口描述为已上线能力。

## 作品简介

材智通是一款面向大学生的校园一站式服务小程序，设置首页、机会、服务、互助、我的五个入口，整合机会通知、材料预检、场地预约、报修、失物招领、二手互助与个人成长记录，并提供AI校园助手入口及学生认证人工审核，提升校园信息获取和事务办理效率。

## 创意来源

创意源于校园生活中信息分散、通知易漏、材料重复准备、预约报修入口繁杂和互助沟通低效等常见问题。希望用一个小程序串联“发现机会—准备材料—办理服务—校园互助”，以清晰流程、进度可查和权限隔离减少奔波，让校园服务更易用、更可信。

## 运行环境

微信开发者工具与微信客户端；后端采用JDK 21、Spring Boot 4、MySQL 8、Redis、S3兼容存储和ClamAV。开发检查需Node.js与Maven，正式部署需HTTPS域名及微信相关配置，AI能力需配置模型服务。
